使い方(AutoCAD)
  • コピーした文字列(例: N9(0^-0.036))を寸法値の後ろに貼り付け → マルチテキスト編集で 0^-0.036 の部分を選択し「スタック」で上下段公差表示になります。寸法数値は含みません。
注記
  • キー溝幅の公差クラス: 滑動形 = 軸 H9 / 穴 D10、普通形 = 軸 N9 / 穴 Js9、締込み形 = 軸・穴とも P9(JIS B 1301:1996 付表4)。
  • 溝深さの許容差 t1・t2: 2×2〜6×6 は +0.1/0、8×7〜32×18 は +0.2/0、36×20 以上は +0.3/0。
  • 溝の隅R r1,r2 はキーサイズにより範囲が変わります。表示された範囲内で加工してください。
  • d−t1(軸側)・d+t2(穴側)は測定・図面記入用の換算値。d−t1 は t1 の許容差を符号反転(0/−)して適用。
  • 対応国際規格に無い括弧付きサイズ(7×7, 15×10, 24×16, 35×22, 38×24, 42×26)は新設計非推奨のため収録していません。
  • 適応軸径は一般用途の目安です。トルクに対しキーが十分な場合はより太い軸に使用可(その場合 t1・t2 の修正を推奨)。
  • 参考: キー本体の許容差は 幅 b = h9、高さ h = h9(6×6以下)/ h11(8×7以上)。
